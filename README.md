# explainable-graph-based-recommender
This project presents an explainable graph-based recommender system for residential property search, designed to improve both recommendation quality and interpretability in high-stakes housing decision-making. Unlike traditional recommender systems that rely on latent representations or simple feature matching, this approach constructs a comparable-property graph that explicitly models relationships between properties based on key attributes such as location, price, size, property type, and amenities.

The system not only provides ranked property recommendations but also generates faithful explanations by leveraging observable comparable-property evidence, making the recommendation process more transparent and user-understandable.
